# WordUp — интерактивный тренажёр словообразования ОГЭ

Сайт в лавандово-жёлтом игровом стиле для изучения лексики английского языка и подготовки к заданию на словообразование ОГЭ.

## Возможности
- 198 словообразовательных семейств и 469 словоформ из двух исходных файлов (таблица Wordbuilding 2025 и «ОГЭ Словообразование»).
- Карточки с переворотом, переводом, озвучкой и отметками «Знаю / Повторить».
- Викторина по переводам с английского на русский и с русского на английский.
- 219 контекстных заданий с пропущенным словом, проверкой ответа и подсказками.
- Поиск по словарю, фильтры, прогресс, серия дней, XP и достижения.
- Адаптация под телефон и компьютер.

## Запуск и публикация
Весь сайт встроен в файл `index.html`, а иллюстрация находится в `assets/hero.svg`. **Установка, сборка, сервер и регистрация не нужны.**

Для включения публичного сайта:
1. Откройте [Settings → Pages](https://github.com/Zenner97/vocab/settings/pages).
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
4. После успешной публикации адрес будет: https://zenner97.github.io/vocab/

Прогресс каждого ученика сохраняется только в локальном хранилище его браузера (`localStorage`). Он не передаётся учителю и не синхронизируется между устройствами.

## Источники
- `Slovoobrazovanie_Oge_2025.pdf` — 7-страничная таблица Wordbuilding 2025.
- `ОГЭ Словообразование(4).docx` — 2-страничный список словообразовательных пар.

Семейства объединены, дубликаты удалены, явные опечатки нормализованы (например, *amze → amaze*, *hinter → hunter*). Предложения составлены специально для тренажёра, а не взяты из учебников.

Для изменения переводов, слов или заданий откройте `index.html`: словарь находится в переменной `window.WORD_FAMILIES`, предложения — в `window.SENTENCE_TASKS`.
